What this mockup adds to the dashboard:
1. Room power cards — per-room watt totals with proportional bars and device breakdown
2. All-time kWh donut — uses the *_electric_consumption_kwh entities already in HA
3. Device table — combines live watts + cumulative kWh in one sortable view
4. Washer included in overall power tracking (currently separate)

Data sources: All values come from existing HA entities — no new integrations needed. The bogus guestbedroomwindow_electric_kwh (5.3M kWh) would be excluded.

Washer → Bathroom suggestions:
• Add sensor.bathroom_washer_power to the Bathroom powerSensors array in shared.js
• Add sensor.bathroom_washer_power to LC_POWER_SENSORS so it counts toward total power
• Add sensor.bathroom_washer_energy to liveData.power for kWh tracking
• Optionally add sensor.bathroom_washer_energy_difference for per-cycle cost estimates
